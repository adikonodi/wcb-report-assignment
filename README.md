# WCB Assignment – Medical Expense & Worker Progress Reports

## Overview

This repository contains my first assignment implementing two dynamic web-based reports based on the reference PDF documents provided as part of the assignment.

The project is developed using:

- HTML
- CSS
- JavaScript

The main objective is to reproduce the structure, styling, and dynamic behaviour of the provided PDF references while allowing the user to enter and update data through the browser.

Both exercises include dynamic data handling, PDF-style layouts, WCB branding, report generation, and demonstration videos.

---

## Exercises

### Exercise 1 – Medical Expense Request

The first exercise is a dynamic medical expense report based on the provided medical and travel expense reference document.

It supports entering and managing different expense categories, including:

- Prescription drugs
- Over-the-counter drugs
- Medical supplies
- Parking expenses
- Mileage
- Transportation expenses
- Worker information and claim details

The report dynamically calculates expense totals and generates a structured report based on the entered information.

### Exercise 2 – Worker Progress Report

The second exercise is a dynamic worker progress report based on the provided reference document.

It includes dynamic sections for information such as:

- Worker and claim information
- Return-to-work details
- Recovery information
- Pain information
- Medical treatment
- Home exercises
- Medication
- Additional information
- Worker application information
- Report and submission dates

The report is generated dynamically from the information entered through the browser.
