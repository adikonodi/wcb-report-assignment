# WCB Assignment – Medical Expense & Worker Progress Reports

## Overview

This repository contains my first assignment implementing two dynamic web-based reports based on the reference PDF documents provided as part of the assignment.

The project is developed using:

- HTML
- CSS
- JavaScript

The main objective is to reproduce the structure, styling, and dynamic behaviour of the provided PDF references while allowing the user to enter and update data through the browser.
